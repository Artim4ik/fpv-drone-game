# GREY CORRIDOR // Вельгород (+ BLACK KITE FPV)

> **Вымысел.** Город Вельгород, долина Крежны, ТИД, все персонажи, документы,
> подразделения и события игры придуманы. Совпадения случайны.

Кинематографичная мультиплеер-игра в браузере (Three.js + React + Vite):

- **Глава 1 — Вельгород:** живой процедурный город, пешеходы, трафик,
  белый микроавтобус патруля с ИИ (патруль → заметил → остановился →
  двери → проверка документов), система вымышленных документов,
  задержание с QTE, поездка в микроавтобусе.
- **Глава 2 — учебный центр «Северный»:** бег, полоса препятствий,
  стрельбище, финальная оценка, прокачка характеристик.
- **Глава 3 — долина Крежны:** руины, траншеи, блокпосты, 4 миссии,
  combat-ИИ, оборона поста, эвакуация.
- **Мультиплеер 1–16:** авторитативный WebSocket-сервер (20 Гц),
  синхронизация позиций/анимаций/глав, общий чат, общие задачи от хоста.
  Без сервера игра работает в офлайне.

Оригинальная FPV-игра репозитория **BLACK KITE** сохранена и доступна
из лаунчера.

## Быстрый старт

```bash
npm install
npm run server:install

# терминал 1 — мультиплеер-сервер (ws://localhost:8787/mp)
npm run server:dev

# терминал 2 — клиент (http://localhost:5173)
npm run dev
```

Откройте клиент в 2+ вкладках/браузерах — игроки увидят друг друга.
Клиент подключается на тот же хост по пути `/mp` (в dev vite
проксирует `/mp` на сервер). Переопределить URL: `localStorage.grey_mp_url`
или `VITE_MP_URL`.

## Сборка

```bash
npm run build      # клиент → dist/ (один HTML-файл)
npm run preview    # предпросмотр сборки
npm run server:check  # typecheck сервера
```

## Управление

WASD — движение • мышь — камера (клик — pointer lock) • Shift — бег •
E — действие / вырываться • C — присесть • Tab/F — документы •
ЛКМ — огонь • ПКМ — прицелиться • R — перезарядка • 1–4 — реплики •
Esc — пауза.

## Структура

```
shared/protocol.ts      # общий сетевой протокол (клиент + сервер)
server/src/index.ts     # авторитативный сервер (ws, 20 Гц)
src/survive/
  Game.ts               # оркестратор: игрок, главы, бой, миссии, VFX
  world.ts              # процедурные зоны + коллизии
  actors.ts             # гуманоиды + ИИ (гражданские, противник)
  minibus.ts            # микроавтобус: модель + ИИ патруля
  audio.ts              # процедурный WebAudio-движок
  net.ts                # сетевой клиент (offline-safe)
  textures.ts           # процедурные canvas-текстуры
  types.ts              # типы, документы, качество, сейвы
  hud.tsx               # HUD, диалоги, бумажник, брифинг
  SurviveScene.tsx      # React-монтирование игры
  grey.css              # стили
src/fpv/FpvApp.tsx      # оригинальная FPV-игра
src/game/DroneScene.tsx # оригинальная 3D-сцена дрона
```

## Известные ограничения

- Патрульный микроавтобус и NPC симулируются локально у каждого клиента
  (сервер синхронизирует игроков, чат и задачи); полная серверная
  авторитетность NPC — следующий приоритет.
- Физика — упрощённая (AABB-коллизии, без Rapier) ради веса сборки.
